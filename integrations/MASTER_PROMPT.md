# Integration Page Build Prompt

You are building an integration landing page for nycclaw.com. Follow these instructions exactly.

## Your task
1. Research the platform's API capabilities, webhook support, and what can be automated
2. Build a complete HTML page following the template structure below
3. Write the file to the specified output path

## Page structure (follow this exactly, in this order)
1. **Head** - title tag, meta description, OG tags, canonical URL, schema markup (Service + FAQ), same CSS as template
2. **Nav** - identical to template (Industries dropdown + links)
3. **Hero** - badge "Platform Integration", punchy H1 (benefit-driven, NOT the keyword), subtitle explaining the integration, CTA buttons
4. **Stats bar** - 4 key numbers relevant to this platform
5. **Pain points** - 4 cards about why the platform is powerful but the user is still the bottleneck
6. **Capabilities** - 6 cards showing what OpenClaw does through this platform's API (be specific to the platform's actual features)
7. **What is OpenClaw** - same 2-paragraph explainer section
8. **Use cases** - 3 industry-specific scenarios showing the integration in action
9. **How it works** - 3 steps (connect, configure, operate)
10. **Pricing** - 3 tiers: Free discovery / $1,200 remote / $2,400 in-person. Stripe links: remote=https://buy.stripe.com/5kA3e9gAVbAY2w84gi in-person=https://buy.stripe.com/7sI5ml8ej7kI5Ik6oq Cal.com=https://cal.com/giovanninyc/15min
11. **FAQ** - 5 questions with schema markup. Always include: "Does this replace [platform]?" and "How long does setup take?"
12. **Related industries** - links to relevant /for/ pages + "View All Industries"
13. **Final CTA** - dark bg, book a free discovery call
14. **Footer** - same as template

## CRITICAL WRITING RULES
1. ZERO em dashes. None. Use periods, commas, semicolons, colons, or parentheses instead.
2. No "Furthermore," "Moreover," "In addition," "It's worth noting," "In today's landscape"
3. No "not just X, but also Y" constructions
4. No "Whether you're a X or a Y"
5. Use contractions: "You're" not "You are", "doesn't" not "does not"
6. Vary sentence length. Short punchy ones mixed with longer ones.
7. No exclamation marks (max 1 on entire page)
8. No buzzwords: "leverage," "cutting-edge," "revolutionize," "game-changer," "seamless," "unlock," "empower," "harness," "supercharge," "elevate"
9. Be specific. "OpenClaw reads the deal record and sends a follow-up email within 60 seconds" beats "OpenClaw provides intelligent automated responses"
10. Write like a smart friend explaining something useful. Not a marketing brochure.
