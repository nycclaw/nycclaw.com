# NYC Claw — Integration Pages: Master SEO & Content Strategy

> Final synthesis from 3 research tracks. 60+ integration concepts, keyword targets, priority tiers, and content plan.

---

## The Play

Build a programmatic `/integrations/` directory — one page per tool — targeting **"[Tool] AI integration"** and **"AI agent for [Tool]"** keywords. This is greenfield SEO territory: competitors (Zapier, Make, n8n) own "integration" and "automation" but **nobody owns "AI agent for [Tool]" yet.** NYC Claw can be the first mover.

Zapier has 60K+ programmatic pages generating 9M+ organic visits. We're not Zapier — but the template approach scales fast. Build 10 pages manually, templatize, then scale to 50+.

---

## URL Structure

```
/integrations/                              → Directory index (all tools, grouped by category)
/integrations/gohighlevel/                  → Individual tool page
/integrations/hubspot/                      → Individual tool page
/integrations/slack/                        → Individual tool page
...
/blog/gohighlevel-ai-employee-vs-openclaw/  → Supporting blog content
/blog/automate-lead-followup-ai/            → Supporting blog content
```

Flat structure. No `/integrations/crms/hubspot/` — unnecessary nesting hurts UX and adds nothing for SEO.

---

## Content Template (Each Integration Page)

Every `/integrations/[tool]/` page follows the same structure:

1. **H1:** `[Tool] + AI Agent Integration`
2. **Hero:** 2 sentences on what OpenClaw does with [Tool] + "Book a Setup Call" CTA
3. **"What can your AI agent do with [Tool]?"** — 4-6 concrete use cases as bullet points
4. **"How it works"** — 3 steps: Connect → Configure → Go (simple, confidence-building)
5. **"Example workflows"** — 2-3 real scenarios with specifics
6. **"Why professional setup?"** — NYC Claw positioning (vs DIY)
7. **FAQ** — 3-5 questions targeting long-tail keywords
8. **CTA** — Cal.com booking link

**SEO per page:**
- Title: `[Tool] AI Integration | Connect [Tool] to Your AI Assistant — NYC Claw`
- Meta: `Set up an AI agent that works with [Tool]. Automate [action 1], [action 2], and more. Professional OpenClaw setup by NYC Claw.`
- Schema: `SoftwareApplication` + `Service` markup

## SEO Quick Wins

1. **Own "AI agent for [Tool]" first.** Low competition, growing search volume. Most competitors target "integration" — we target "AI agent."
2. **Build the directory index page immediately.** Even with just 5-10 live integration pages, the index builds topical authority.
3. **Schema markup on every page.** `SoftwareApplication` + `Service` + `FAQPage` schemas.
4. **Programmatic generation after 10 manual pages.** Build a template, swap tool name + use cases + API details. Same page structure = faster production.
5. **Submit to Google Search Console.** Sitemap with all integration URLs. Request indexing for Phase 1 pages.
6. **Blog content feeds integration pages.** Each blog post targets informational keywords and links to commercial integration pages.
