2. Draft page content based on research

## Research Template
Each vertical gets a `research.md` with:
- Industry overview (NYC context)
- Daily workflow / typical day
- Top 4-6 pain points (with specifics, not generic)
- How OpenClaw actually solves each one (grounded in real capabilities)
- Competitor landscape (who else targets this vertical with AI)
- Key stats / data points
- Persona (who's the buyer?)
- Objections & FAQ
- SEO: target keywords, search intent
