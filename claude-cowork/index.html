What Is Claude Cowork?

Cowork is an agentic mode inside Claude Desktop that handles multi-step knowledge work on its own. You describe the outcome you want. Claude breaks it into steps, executes each one, and delivers finished work.

That's the core difference from regular Claude Chat. In Chat, Claude can only respond to your prompts. It can't touch your files or connect to your tools. In Cowork, Claude reads, edits, and creates files in folders you specify. It connects to Slack, HubSpot, Google Drive, Jira, and dozens of other tools through connectors. It actually completes tasks instead of just describing how you could complete them yourself.

If you've heard of Claude Code, Cowork is the same architecture built for non-developers. Claude Code runs in a terminal for software engineers. Cowork runs in the desktop app for everyone else: marketers, lawyers, accountants, salespeople, operations teams.

What Cowork Can Do

Four core capabilities that separate Cowork from a chatbot.

File and Document Management

Cowork reads, edits, creates, and organizes files on your computer. It can sort a messy Downloads folder, extract invoice data into spreadsheets, rename files with consistent conventions, and create formatted documents from your brand templates.

Real example: one user set up a daily scheduled task that sorts files dropped into an inbox folder, categorizes them by client, and generates a morning summary report.

Web Research and Analysis

Claude can research topics on the web using the Chrome extension or built-in search tool, then synthesize findings into deliverables. Market sizing reports, competitive analyses, pricing research. The output goes straight into PowerPoint or Excel files on your computer.

A marketing power user built a weekly scheduled task that researches trending topics, classifies them by content potential and business impact, and references previous weeks' results so coverage builds over time.

Scheduled and Recurring Tasks

Set up tasks that run daily, weekly, or monthly using the /schedule command. Each scheduled task runs as its own Cowork session with full access to your connectors, plugins, and files. Your computer needs to be awake with Claude Desktop open.

Popular scheduled tasks: morning email briefings, Stripe revenue reports, file cleanup and deduplication, competitive monitoring, Apple Notes tidying, and weekly team presentation prep.

Mobile Task Assignment

Message Claude from your phone and the work executes on your desktop. Same conversation context across both surfaces. You can hand off tasks that use desktop files, connectors, and plugins while you're away from your computer.

Your phone becomes a remote control for your desktop resources. Assign a report on the train, review the finished deliverable when you're back at your desk.

Cowork runs in an isolated VM on your computer. Your files and conversation history stay local.

Plugins and Skills

Plugins make Claude an expert in your specific role. Skills teach it your exact workflows.

Plugins

A plugin is a package that bundles skills, connectors, slash commands, and sub-agents into one installable unit. Think of it as a role-specific configuration for Claude. The Sales plugin knows how to prep for calls, research prospects, and update your CRM. The Legal plugin knows how to review contracts, triage NDAs, and flag compliance risks.

Anthropic ships 11 official plugins: Productivity, Sales, Customer Support, Product Management, Marketing, Legal, Finance, Data, Enterprise Search, Bio Research, and Plugin Create. Each one connects to the tools that role actually uses.

Everything in a plugin is file-based: markdown and JSON. No code, no infrastructure, no build steps. You can fork any official plugin from Anthropic's GitHub repo and customize it for your team.

Full plugins guide →

Skills

Skills are the core way you teach Claude new capabilities. Each skill is a SKILL.md file with YAML frontmatter and markdown instructions. Claude reads it and adds it to its toolkit. Some skills fire automatically when relevant. Others you trigger with a slash command like /weekly-report or /contract-review.

There are two types. Reference skills give Claude domain knowledge it applies to current work: conventions, style guides, brand voice rules. Task skills are step-by-step instructions for specific actions: generating a market report, processing invoices, running a reconciliation.

Skills follow the Agent Skills open standard (agentskills.io), so they work across multiple AI tools. They can include supporting files like templates, example outputs, and validation scripts that Claude loads when needed.

Security and Privacy

How Cowork Protects Your Data

  • Runs in an isolated VM on your local computer
  • Conversation history stored locally, not on Anthropic's servers
  • Claude shows its plan before taking significant actions
  • You control which folders and connectors Claude can access
  • Connectors use OAuth with scoped permissions

Best Practices

  • • Use a dedicated working folder. Don't grant access to your entire filesystem.
  • • Limit browser access to trusted sites to reduce prompt injection risk.
  • • Review scheduled tasks carefully before enabling. They run without active monitoring.
  • • Stick to verified plugins and connectors. Each one extends Claude's scope.
  • • Keep sensitive credentials out of working folders.
