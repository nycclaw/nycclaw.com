What Are Cowork Connectors?

A connector links Claude to an external tool. It lets Claude pull data from and take actions inside apps like your CRM, project tracker, email, or file storage. Without connectors, Claude can only work with what you paste into the conversation. With them, it goes straight to the source.

Under the hood, every connector is an MCP server. MCP stands for Model Context Protocol, an open standard created by Anthropic and maintained at modelcontextprotocol.io. It's the same protocol that powers tool use across the Claude ecosystem. Each MCP server exposes a set of actions (like "search contacts" or "create issue") that Claude can call during a conversation.

The key detail: connectors respect your existing account permissions. If you can't access a certain HubSpot deal or Google Drive folder, neither can Claude. There's no elevated access, no admin backdoor. Claude sees exactly what you see.

How Connectors Work

Setting up a connector takes about 30 seconds.

1

Open a Cowork Session

Launch Claude Desktop and start a Cowork conversation. If you've installed a plugin that requires a connector, Claude will prompt you to authenticate the first time it needs access.

2

Authorize via OAuth

A browser window opens with the standard OAuth flow for that tool. You log in with your existing credentials and approve the specific permissions Claude is requesting. For tools that don't support OAuth, you'll provide an API key instead.

3

One-Time Setup

Authentication persists across sessions. You won't need to re-authorize unless you revoke the token or it expires. The connection details are stored locally in your .mcp.json configuration file, not on Anthropic's servers.

4

Use It

Done. Claude can now pull data from and take actions in the connected tool. Ask it to summarize your Slack threads, update a Jira ticket, draft an email in Gmail, or pull a contact list from HubSpot. No limit on how many tools you connect.

Technical Details

Connectors can run as local servers (via stdio) or remote servers (via HTTP). They're configured through .mcp.json files at the user, project, or managed scope. On Enterprise plans, admins can pre-configure connectors and distribute them across the organization through the plugin marketplace.

Frequently Asked Questions

What is a Claude Cowork connector?
A connector is an MCP (Model Context Protocol) server that lets Claude interact with an external tool like Slack, HubSpot, or Google Drive. Each connector authenticates via OAuth or API keys and respects the permissions of your underlying account. Claude can only see and do what you can see and do.
How many connectors can I use at once?
There's no limit on the number of connected tools. You can authenticate Slack, Google Drive, HubSpot, Jira, and any other available connector simultaneously. Each stays active across sessions after the initial one-time OAuth setup.
Do connectors share my credentials with Anthropic?
No. Cowork runs in an isolated virtual machine on your local computer. OAuth tokens are stored locally, and your credentials never pass through Anthropic's infrastructure. Claude only gets scoped access to the specific permissions you authorize during the OAuth flow.
Can I build a custom connector for an internal tool?
Yes. MCP is an open specification maintained at modelcontextprotocol.io. Anyone can build a custom MCP server for any tool or API. We build custom connectors for clients who need to connect Cowork to proprietary systems, internal databases, or niche SaaS tools that don't have an official connector yet.
What happens if a connector loses its authentication?
If an OAuth token expires or is revoked, Claude will prompt you to re-authorize the next time a plugin tries to use that connector. The re-auth process takes about 30 seconds and follows the same browser-based OAuth flow as the initial setup. No data is lost when a connector disconnects.
