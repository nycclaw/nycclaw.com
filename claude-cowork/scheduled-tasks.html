What Are Scheduled Tasks?

Scheduled tasks are recurring automations inside Claude Cowork. You define a task once, pick a cadence (daily, weekly, or monthly), and Claude runs it automatically at the time you set.

Each scheduled task spins up its own Cowork session. That means it has full access to your connectors (Gmail, Slack, Google Drive, Stripe, HubSpot, and 30+ others), your installed plugins, and any local files or folders you've granted Cowork access to.

You set them up using the /schedule command in any Cowork session, or through the "Scheduled" sidebar panel in Claude Desktop. The setup takes about 60 seconds.

There's one requirement: your computer needs to be awake and Claude Desktop needs to be open for the task to execute. If your machine is asleep at the scheduled time, the task won't run until the next window. This isn't a cloud service. It's an automation running locally on your machine, which also means your data never leaves your computer unless a connector explicitly sends it somewhere.

How to Set Up a Scheduled Task

Setup takes under a minute. Here's the step-by-step process.

1

Open Claude Cowork

Launch Claude Desktop and start a new Cowork session (not a regular Chat session).

2

Open the scheduler

Type /schedule in the message bar, or click "Scheduled" in the left sidebar panel.

3

Choose your cadence

Select daily, weekly, or monthly. Pick the specific time and, for weekly tasks, the day of the week.

4

Define the task

Write clear instructions for what Claude should do. Be specific: name the connectors, files, folders, and output format you want. The more detail you provide, the better the results.

5

Confirm and review

Claude shows you a summary of the task, schedule, and connectors it'll use. Confirm to activate. You can edit or delete any scheduled task later from the Scheduled sidebar.

Requirements and Limitations

Scheduled tasks are powerful, but they run with some constraints worth knowing upfront.

Your computer must be awake

Scheduled tasks run locally, not in the cloud. If your machine is asleep, shut down, or in hibernation mode when a task is due, it won't execute. For daily morning tasks, set your computer's energy settings to wake before the scheduled time.

Claude Desktop must be open

The app doesn't need to be in the foreground, but it does need to be running. Add Claude Desktop to your login items so it launches automatically when your computer starts.

Tasks run without active monitoring

You won't be prompted to approve each step during a scheduled run. Claude follows the instructions you gave during setup. Review your task definitions carefully before activating them, especially tasks that create, move, or delete files. Test with a manual run first.

Usage counts against your plan

Each scheduled task consumes compute like any other Cowork session. If you're on a Pro plan with limited usage, be mindful of how many tasks you schedule and how complex they are. Max and Enterprise plans give more headroom.

Frequently Asked Questions

What are Claude Cowork scheduled tasks?
Scheduled tasks are recurring automations inside Claude Cowork that run at a cadence you choose: daily, weekly, or monthly. Each task runs as its own Cowork session with full access to your connectors, plugins, and local files. You set them up using the /schedule command or the Scheduled sidebar in Claude Desktop.
Does my computer need to be on for scheduled tasks to run?
Yes. Your computer must be awake and Claude Desktop must be open for scheduled tasks to execute. If your machine is asleep or the app is closed when a task is due, it won't run until the next scheduled window. For morning tasks, configure your computer's energy settings to wake a few minutes before the scheduled time.
How many scheduled tasks can I run at once?
Each scheduled task runs as its own Cowork session, so only one task executes at a time. You can queue multiple tasks at different times throughout the day. The number of tasks you can schedule depends on your Claude plan's usage limits, since each task consumes compute like any other Cowork session.
Can scheduled tasks connect to external tools like Slack and Google Drive?
Yes. Scheduled tasks have full access to any connectors you've configured in Claude Desktop. A morning briefing can pull from Gmail, a revenue report can read Stripe data, and a team update can post directly to Slack. You configure connectors once, and every scheduled task can use them.
What happens if a scheduled task produces an error?
Each scheduled task creates a full session log you can review in Cowork's history. If a task fails or produces unexpected results, open the session to see exactly what Claude did at each step. Then adjust the task instructions. We recommend reviewing output from new tasks for the first few runs before trusting them fully.
