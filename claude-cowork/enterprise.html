Admin Controls and Management

IT teams need visibility and control. Both Team and Enterprise plans give admins tools to manage how Cowork runs across the organization.

Org-Wide Cowork Toggle

Admins flip a single switch to enable or disable Cowork for the entire organization. There's no per-user toggle. If you need Cowork for only certain teams, you'll need to contact Anthropic to discuss options.

Plugin Installation Preferences

Control how plugins appear to your team. Set any plugin to auto-install (deployed to every member automatically), available (visible in the marketplace for members to install themselves), or hidden (not shown at all). This gives IT full control over which tools your team can access.

Plugin Installation Scopes

Plugins can be installed at four scopes: user (applies to one person across all projects), project (applies to a specific project folder), local (applies only to the current conversation), or managed (org-wide, read-only, controlled by admins). Managed scope is what makes Enterprise deployments consistent across hundreds of users.

OpenTelemetry Tracking

Both Team and Enterprise plans support OpenTelemetry for monitoring usage, cost, and tool calls. Track which connectors your team uses most, how many scheduled tasks run each week, and where compute is being spent. This data helps you optimize your rollout and justify ROI to leadership.

Organization Plugin Marketplaces

Your organization's plugin marketplace is a curated collection of tools built for your specific workflows. Organization owners create and manage it through Organization settings, under the Plugins section.

You're not limited to Anthropic's 11 official plugins. Fork an official plugin and customize it for your industry. Build something entirely new for a workflow that doesn't have a plugin yet. Or mix and match: use the official Sales plugin for prospecting, then add a custom plugin for your proprietary quoting process.

Auto-Install

Deployed to every team member the moment they open Claude Desktop. No action required from the user. Best for core plugins your whole org needs.

Available

Visible in the organization marketplace for members to browse and install. Good for department-specific plugins that not everyone needs.

Hidden

Not shown in the marketplace. Use this for plugins still in development, deprecated plugins you haven't removed yet, or tools restricted to admins only.

For example, a law firm might auto-install the Legal plugin for all attorneys, make the Productivity plugin available for paralegals to install themselves, and hide an experimental contract-analysis plugin that's still being tested. An accounting firm could auto-install a custom tax-prep plugin during filing season, then hide it after April 15.

Security for Enterprise

Cowork's architecture keeps sensitive data on your machines. Here's what enterprise IT teams need to know.

Local Execution

Cowork runs inside an isolated virtual machine on each user's local computer. Conversation history is stored locally, not on Anthropic's servers. This means Cowork data does not appear in Anthropic's audit logs, compliance API, or data exports. It's also not subject to Anthropic's standard data retention policies.

Connector Permissions

All connectors use OAuth with scoped permissions. When Claude connects to HubSpot, Google Drive, Jira, or any other tool, it gets only the access you authorize. Your CRM credentials never pass through Anthropic's infrastructure.

Action Approval

Claude shows you its plan before taking significant actions. File edits, connector calls, and scheduled task changes all surface for review. You approve or reject before anything executes.

No Audit Logging (Yet)

Because Cowork data lives locally, it doesn't currently appear in centralized audit logs. If your compliance team requires server-side logging of all AI interactions, this is a gap to be aware of. OpenTelemetry tracking provides usage metrics, but full conversation-level audit trails aren't available today.

Best Practices for Enterprise Deployments

  • 1. Create dedicated working folders for Cowork. Don't give it access to your entire home directory.
  • 2. Limit browser access to only the sites Claude needs for specific tasks.
  • 3. Review scheduled tasks carefully before enabling them. Each task runs with full access to your connectors and plugins.
  • 4. Use only verified plugins from your organization marketplace or Anthropic's official library.
  • 5. Monitor OpenTelemetry data weekly to catch unexpected usage patterns early.

How We Roll Out Cowork for Your Team

We've deployed Cowork for real estate teams, law firms, accounting practices, and consulting groups. Here's the process we follow every time.

1

Identify Pilot Teams

We pick 2-3 teams with repeatable, high-volume workflows. Sales teams doing weekly pipeline reports. Paralegals drafting the same contract templates. Accountants reconciling monthly financials. These are the workflows where Cowork delivers the fastest ROI.

2

Build Custom Plugins

We create plugins tailored to each pilot team's specific processes. A plugin bundles skills, connectors, slash commands, and sub-agents into a single package. Instead of configuring everything from scratch, users install one plugin and they're ready to go.

3

Configure Connectors

We connect Cowork to your CRM (HubSpot, Salesforce), project management tools (Jira, Asana, Linear), communication platforms (Slack, Gmail), and file storage (Google Drive, Dropbox). Each connector uses OAuth with scoped permissions so Claude only accesses what it needs.

4

Write Global and Folder Instructions

Quality output depends on context. We write global instructions that define your company's tone, formatting standards, and common terminology. Then we add folder-level instructions for specific project types. This is the difference between generic AI output and work that sounds like your team wrote it.

5

Train Your Teams

We run training sessions (remote or in-person) covering how to use Cowork, how to write good prompts for autonomous tasks, and how to review Claude's work before approving actions. Every team member leaves the session able to run their first Cowork workflow independently.

6

Set Up Scheduled Tasks

For recurring deliverables, we configure scheduled tasks. Monday morning pipeline summaries. Friday afternoon timesheet reminders. Monthly client report drafts. These run automatically so your team doesn't have to remember to start them.

7

Ongoing Plugin Updates

Cowork is still in research preview. Anthropic ships updates regularly, and those updates sometimes break existing plugin configurations. We maintain your plugins as the platform evolves, so your team never wakes up to a broken workflow.

Frequently Asked Questions

What's the difference between Claude Team and Enterprise plans?
Team costs $20/seat/month for 5-75 people. It includes self-serve management, the Slack connector, standard and premium seat types, and full Cowork access. Enterprise is custom-priced for larger organizations and adds admin controls like org-wide Cowork toggles, curated plugin marketplaces, managed plugin scopes, and dedicated support from Anthropic.
Can I enable Cowork for only some team members?
Not currently. The Cowork toggle is org-wide on both Team and Enterprise plans: it's on for all members or off for all members. There's no per-user granularity. If you need selective rollout, you'd need to contact Anthropic directly to discuss custom arrangements.
Is Cowork conversation data stored on Anthropic's servers?
No. Cowork runs in an isolated VM on each user's local computer. Conversation history stays on that machine. Cowork data doesn't appear in Anthropic's audit logs, compliance API, or data exports. It's also not subject to Anthropic's standard data retention policies. This is great for privacy but means centralized audit logging isn't available yet.
What is an organization plugin marketplace?
Organization owners can create curated plugin collections and distribute them to all members through Organization settings. You control which plugins are auto-installed for everyone, which are available to browse, and which are hidden. You can include official Anthropic plugins, forked and customized versions, or fully custom builds. Read the full plugins guide.
How long does an enterprise Cowork rollout take?
A typical rollout takes 2-4 weeks from kickoff to full deployment. We start with 2-3 pilot teams, build custom plugins for their workflows, configure connectors, write global and folder instructions, train the teams, and set up scheduled tasks. After launch, we provide ongoing plugin maintenance as the platform evolves. Learn about our consulting process.
